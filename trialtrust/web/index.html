第一次怎么用？

        
      

      
    
        
  1. 
          选事情。选一个类别和具体示例。先用“美食聚会 → 自助餐聚会”体验。
        
    2. 
        
  2. 
          核对后运行。依次填人数、服务方式、预算；选“免费演示”和“自动对比两次”，勾选确认，点击“开始一组对照彩排”。免费演示不调用模型。
        
    3. 
        
  3. 
          看差别和依据。先看“按原条件试”和“遇到变化再试”两张卡，点击一张，下方就是那次的结论。想知道原因，再展开检查依据中的记录。
        
    4. 
        
  4. 
          自己审阅并导出。保留或暂不接受，下载JSON记录。更改任何条件都需要重新勾选确认。熟悉后再选真实模型，启用向量检索会额外调用Embedding。
        
    5. 
      

      

        自定义文字先生成本地替身，再亲自去除遗漏的个人资料。只有明确映射到支持场景的四项条件才能彩排；否则会给出缺失信息与证据清单。
