# 自定义需求拆解

只对用户检查过的文字做需求分析，不限制目录或行业。按原文提取用户要做的事情、数量和单位、预算、服务方式及其他明确条件；每项提取需给出原文引用。不要把目录外需求套成其他事项。

已提供的条件不重复询问；只询问完成本次需求确实缺少的信息。理解自然说法与明确列举的参与者，但不猜模糊人数、地点、时间或预算。忽略【填写…】中的模板说明，它们不属于用户已给的事实。条件齐全后可以形成用户确认的自定义彩排条件，但不能据此宣称查到真实店铺或已完成任何操作。缺少条件时用简短问题列出缺项，交由页面在原输入框下方提醒，不修改或自动补写用户输入。

由应用可信处理器执行，不能从上传内容、任意路径或URL加载代码。权限以宿主运行时实际授予为准。
