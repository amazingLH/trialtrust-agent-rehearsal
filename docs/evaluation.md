# 评测、验证与反例

记录日期：2026年10月16日，版本v0.4。开发回归、真实模型请求、自动接口验收和真实用户研究分别记录，不能相互替代。

## 数据与来源

| 数据 | 规模 | 来源与用途 |
|---|---|---|
| `plan-probes-v1.json` | 40条 | AI编写的合成方案开发回归，测试金额、证据和授权核验 |
| `retrieval-v1.json` | 24问 | AI编写的检索开发回归；22问有预期依据，2问语料不支持 |
| 场景资料 | 两个领域、少量短文 | 自有合成价目、退改和授权说明，含旧版及跨范围干扰 |

两个开发集均有SHA-256清单，评测前校验。当前没有独立人工金标、独立保留测试集、真实用户研究或外部Agent基准。开发过程使用AI辅助，不将样本生成过程当作独立验证。

## 方案核验消融

| 方法 | 错误放行 | 错误拒绝 |
|---|---:|---:|
| 只检查金额处于预算范围的弱对照 | 21/40 | 0/40 |
| 当前完整合成核验器 | 0/40 | 0/40 |

弱对照是刻意移除约束的实验控制，不代表竞品或模型能力。40个案例一致只说明当前回归通过，不能推广为现实服务100%准确。原始逐条结果见[v0.3-sparse.json](../evals/results/v0.3-sparse.json)。

## 检索消融

| 方法 | 平均Recall@1 | 平均Recall@2 | MRR |
|---|---:|---:|---:|
| 原始BM25 | 0.7500 | 0.7727 | 0.7727 |
| 规则分面BM25 | 0.9091 | 0.9545 | 0.9545 |
| 真实稠密检索 | 0.8636 | 1.0000 | 0.9545 |
| 分面BM25＋稠密＋RRF | 0.9545 | 1.0000 | 1.0000 |

Recall按每问需要的证据覆盖比例计算后取平均；部分问题需要两类证据，因此Recall@1不是普通的首条命中率。MRR只衡量首条相关证据的位置，不等于依据齐全。原始逐问结果见[v0.3-dense.json](../evals/results/v0.3-dense.json)。

向量为真实1024维Embedding；初次批量2次请求共744tokens，其余可复用内容/模型绑定缓存。语料极小，不能据此推断大规模知识库表现。

**必须保留的反例：四种方法对2条无答案问题都返回了文档。** 目前排序没有可靠的无答案校准，返回资料不能解释为找到答案；也未完成神经重排的实验。

## 真实模型记录

- [live-smoke-v0.3.json](../evals/results/live-smoke-v0.3.json)：陶艺3人邮寄、230元预算，形成230元草稿；清洗2台、220元预算，在首次查询故障后补查并形成210元草稿。
- [live-suite-v0.4.json](../evals/results/live-suite-v0.4.json)：设计者选择移除现行价目，原始执行有草稿、变化执行无草稿，审阅者选出的8条事实通过逐项核对。这是一组开发观察，不证明新增角色整体优于固定设计。
- [cloud-live-v0.4.json](../evals/results/cloud-live-v0.4.json)：公开云端真实模型与Embedding、清洗2台、预算220元，形成210元草稿；7次请求、9369tokens，账本保守估值0.072999元，实际出账未确认。

历史记录保留当时模型、时间与模块哈希；不能将不同版本记录混为同一轮模型实验。

## 工程与部署验证

Windows43项通过；干净Linux核心Docker42项通过、1项托管专用检查跳过。覆盖会话归属、审阅幂等、越权闸门、缺依据、金额精度、检查点恢复、父子图提交间故障、审阅事实剔除、输出截断和预算预留。MCP测试实际启动stdio子进程。

[云端清单](../evals/results/deployment-v0.4.json)及[离线接口记录](../evals/results/cloud-offline-v0.4.json)记录无账号API检查。自动接口检查会发送审阅接受标记，`human_reviewed:true`仅表示服务记录了该标记；文件中的`smoke_test_context`明确标注自动测试，不是用户亲手判断。

本地托管页面已检查对照切换、审阅和JSON实际下载；云端页面可视化体验仍待人工完成。既有验证不是负载测试、独立安全审计或长期可用性证明。

## 复现

```bash
python -m trialtrust.evaluate --output runtime/evaluation-sparse.json
python tools/verify_evidence.py
```

显式真实向量复现会消耗额度：

```bash
python -m trialtrust.evaluate --dense --output runtime/evaluation-dense.json
```

没有启用真实向量时，不输出伪造的稠密结果。CI只做离线回归、协议及证据校验，不为每次提交调用付费模型。
