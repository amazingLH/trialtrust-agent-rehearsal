## 本地验证

- Windows Python回归120项通过；门户消息Node测试3项通过。
- 浏览器1600×1000：左栏宽286px；右侧四张步骤卡片同宽同横坐标，按1→2→3→4排列；第4步是独立卡片。
- 实际离线自助餐对照完成；保留审阅后，新建会话再切回原会话，原结果可读，确认框保持未选。
- 浏览器390×844：初始侧栏隐藏，不产生横向滚动；打开后背景操作区inert。Esc关闭后焦点回到入口；Shift+Tab从关闭按钮循环到最后可见摘要，不进入折叠记录按钮。
- 发现并修复：闭合details中的按钮仍可能具有布局矩形，键盘循环改用checkVisibility过滤。

本轮没有付费模型调用；离线轨迹仅验证应用流程，不代表真实模型效果。会话依然依赖24小时匿名身份，不提供永久记录或账号同步。
