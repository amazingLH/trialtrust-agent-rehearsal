# 账号与SQLite存储

## 用户操作

1. 打开公开工作台，选择“注册账号”，填写3—32位字母、数字或下划线的用户名及至少10个字符的密码，两次输入保持一致。密码UTF-8编码最多72字节，中文占多个字节。
2. 如果检测到仍有效的旧匿名记录，可主动勾选关联；默认不关联。过期身份或其他浏览器的记录不能据会话ID认领。
3. 注册后保存恢复码，再进入工作台。它只在本次显示；下载文件仅含用户名和恢复码，不含密码，应自行安全保管。
4. 后续用用户名和密码登录。左侧“账号设置”可修改密码，“退出登录”撤销当前会话；修改密码或恢复密码会撤销全部登录会话。
5. 忘记密码时使用“恢复码”设置新密码。恢复成功后旧码失效，必须保存新码。没有绑定邮箱或手机号，丢失密码和恢复码后没有自助找回方式。

## 模块与技术

| 模块 | 实现 |
|---|---|
| 入口 | 原生HTML/CSS/JavaScript及原创SVG太空小托；漂浮、眨眼、星点动效，支持减少动画偏好和手机布局 |
| 接口 | FastAPI与严格Pydantic输入校验；验证错误不回显密码；业务API默认必须登录 |
| 密码 | bcrypt 5.0.0，随机盐及cost=12；只保存完整哈希，禁止明文、静默截断或快速SHA密码哈希 |
| 恢复 | 256位随机恢复码，仅保存SHA-256摘要；高熵随机码不同于人类密码，使用后轮换 |
| 会话 | 256位随机令牌、8小时有效期、服务器保存摘要，可即时撤销；稳定user_id归属历史 |
| 浏览器绑定 | 服务器签发随机标识，SQLite事务与唯一约束保证同一标识只注册一次，不作为登录凭据 |
| 限流 | SQLite持久计数，按来源和用户名限制登录/恢复；不依赖内存，服务重启不清空限制 |
| 数据 | Python sqlite3参数化SQL，BEGIN IMMEDIATE写事务；数据库自动增量建表，旧表和数据保留 |
| 备份 | 启动前SQLite backup一致性快照，同一天只做一次，保留最近3个日期的私有备份 |

默认使用HttpOnly会话Cookie，HTTPS加Secure。魔搭跨站iframe可能屏蔽Cookie，托管入口提供同源短时令牌回退；账号令牌仅存sessionStorage，不放localStorage、URL或公开文件。关闭标签页后可能需要重新登录。浏览器注册标识可保存在localStorage，它不具备读取账户数据的权限。个人模板和选中会话在浏览器中按user_id分开保存；个人模板尚未跨设备同步。

服务默认强制账号登录；create_app(require_accounts=False)仅用于显式旧版迁移回归，不存在远程参数或部署环境开关可关闭登录。历史匿名专项回归明确启用此模式；新增账号回归验证生产默认边界。

## SQLite怎样在魔搭运行

魔搭原生托管与独立Docker入口都使用TRIALTRUST_RUNTIME=/mnt/workspace/trialtrust/web。账号、哈希、登录会话、浏览器绑定及历史元数据在web.sqlite；各轮报告/检查点在同一运行目录下，费用账本在上层usage.sqlite。Dockerfile只复制源码与依赖，不复制运行目录；目录不是镜像的一部分。

魔搭提供的/mnt/workspace用于持久化。仍需对具体空间验证重新部署后的账号、会话与数据标识，不能仅凭路径保证。最新实测见[账号验证](validation-accounts.md)。容器的进程标识应变化，数据库存储标识及历史应保持。

备份位于web/backups，数据库与备份均不通过Web路由提供。容器以非root用户运行，新文件默认umask=077；本地可设置0600权限。魔搭挂载盘拒绝chmod时保留平台管理的权限，不因此停机；意外I/O错误仍抛出，不伪装为正常存储。备份与原库位于同一平台存储，不是灾难恢复服务：删除/迁移空间或平台存储故障仍可能丢失。未引入外部数据库、短信、邮箱或额外收费资源。

## 限制

浏览器限制不是物理设备识别：清理数据、无痕或更换浏览器可绕过；共享IP也不能等同设备。本实现不使用侵入式硬件指纹，不承诺绝对防多账号。多用户登录与数据隔离已加入验证；当前仍是单进程、受限规模的SQLite应用，不宣称多副本或大并发生产能力。


参考：[魔搭官方创空间说明](https://modelscope.cn/skills/modelscope/modelscope-studio)、[OWASP密码存储说明](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。本版使用bcrypt并明确72字节输入限制；其他实现可评估Argon2id。
