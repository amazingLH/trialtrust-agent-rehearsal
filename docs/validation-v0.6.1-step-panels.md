# 四步界面的渐进展示验证

日期：2026-10-19。界面调整基于应用提交227544d之后的工作区，使用独立本地运行目录和离线示例；未调用付费模型。

## 修改

- 第一步提供“自己选择需求 / 使用条件模板”两条入口，一次只显示对应的选择器。应用模板自动填写同一份实际条件，无需再选具体需求；手动路径不依赖模板。当前需求单独显示，仍需在第二步核对确认。
- 执行者说明与确认条件明细放入默认折叠区；工具证据、技能调用也默认折叠，可随时展开。
- 第三、第四步始终显示标题；首次或重新开始仅展示紧凑等待提示。运行中仅开放实际进度，有报告后开放明细和审阅。失败无报告时不显示审阅按钮。

## 实际浏览器结果

本地8776：首次打开第三、第四步均可见，result-content及review-content均不可见；模板路径实际填入2人自助餐190元，不操作手动需求选择器即可运行。实际捕获运行中状态：第三步展示进度、第四步等待。离线对照结束后说明、证据、技能均折叠；展开说明可读到执行者原文与确认条件，收起后内容隐藏。点击“本会话再试一次”后旧详情与审阅消失，两个步骤标题仍保留。切回手动路径选下午茶，当前需求、费用预览同步更新且确认取消。
